## 🛠️ Installation & Play Guide

### 1. Prerequisites
Ensure your environment is ready for C++ compilation:
* **Linux:** `sudo apt install build-essential`
* **Windows:** Use [MinGW](https://www.mingw-w64.org/) or [WSL](https://learn.microsoft.com/en-us/windows/wsl/install).

### 2. Setup

```bash
git init
git clone https://github.com/vikasingh0897/Fun-With-CPP.git
```

### 3. Build & Play

#### On Linux and macOS:

```bash
cd Fun-With-CPP
cd build
cmake ..
make
./Game
```

#### On Windows (using MinGW):

```bash
cd Fun-With-CPP
cd build
cmake -G "MinGW Makefiles" ..
mingw32-make
Game.exe
```

### 4. Cleanup
```bash
rm -rf build
```
